## Checked and NOT vulnerable (aspirational traps avoided)
- Token replay after logout: blacklist + per-user revocation, fail-closed in prod (keycloakAuth.ts:156-180, 385) — OK in prod.
- Session fixation: random state cookie + random jti (keycloakAuth.ts:269,325) — OK.
- OTP brute force: bcrypt-hashed, 10-min expiry, 5-attempt lockout, single-use, identity-bound (pinReset.ts:29-34,225-255) — OK.
- Permify core client fail-closed by default w/ circuit breaker (permify.ts) — OK; fail-open only in journey guard + env opt-in.
- JWT clock skew: jose default (no tolerance) — not abusable.
- Agent session revocation on PIN reset (pinReset.ts:269) — OK.
